How to play

  1. Press Start.
  2. Click a column (or keys 1–7) to drop a disc.
  3. Get 4 in a row — horizontal, vertical, or diagonal.
  4. In CPU mode you are Red; CPU is Yellow.
  5. Enter / Start begins a new round.
